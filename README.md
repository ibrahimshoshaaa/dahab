
# DAHAB — متجر عبايات وإكسسوارات

متجر إلكتروني (Next.js + Express + Turso/libSQL) مع لوحة تحكم للأدمن.

## التشغيل محليًا

### 1) الباك إند (Express + Turso/libSQL)

```bash
cd backend
npm install
cp .env.example .env   # واضبط Turso + بيانات الأدمن + Cloudinary
npm run dev            # أو: node server.js
```

هيشتغل على `http://localhost:4000`. أول تشغيل يهيّئ الجداول في قاعدة بيانات Turso ويعمل seed لـ 8 منتجات تلقائيًا عند عدم وجود منتجات.

### 2) الفرونت إند (Next.js)

```bash
cp .env.example .env.local   # NEXT_PUBLIC_API_URL افتراضيًا http://localhost:4000
npm install
npm run dev
```

هيشتغل على `http://localhost:3000`.

> ملحوظة: في الإنتاج لازم `NEXT_PUBLIC_API_URL` يشير للـBackend الفعلي. لو الـBackend غير متاح، الواجهة تعرض حالة تعذر التحميل بدل استخدام بيانات وهمية.

## لوحة الأدمن

`http://localhost:3000/admin/login`

بيانات الدخول يتم تحديدها من `ADMIN_USER` و`ADMIN_PASS` في متغيرات بيئة الـBackend. لا تضع كلمة مرور الإنتاج داخل GitHub.

الجلسة الإنتاجية تستخدم Cookie محمية HttpOnly وموقعة بـ`ADMIN_SESSION_SECRET`، مع انتهاء صلاحية الجلسة وحماية Origin للطلبات الحساسة.

من اللوحة تقدر:
- تشوف كل الطلبات، تفلترها بالحالة، وتحدّث حالة كل طلب.
- تضيف/تعدّل/تحذف منتجات، وتتحكم في ظهورها بالمتجر (active/hidden).

## تتبع الطلب

العميل يقدر يتابع طلبه من `http://localhost:3000/track` باستخدام كود التتبع الذي يظهر بعد إتمام الطلب.
